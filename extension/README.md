# Oblivion Focus & Notification Shield — Chrome Extension Setup Guide

Oblivion is fully packaged as a Chrome Popup Extension with built-in Focus Time Tracking, Screen Keep-Awake, and Do Not Disturb Notification Blocking.

---

## 🚀 How to Install in Google Chrome (Step-by-Step)

1. **Download or Export Extension Files**:
   - Locate the `/extension` directory in this codebase (contains `manifest.json`, `popup.html`, `popup.js`, `background.js`).

2. **Open Chrome Extensions Manager**:
   - In your Google Chrome address bar, navigate to: `chrome://extensions/`
   - Or click **Menu (3 dots)** → **Extensions** → **Manage Extensions**.

3. **Enable Developer Mode**:
   - Turn on the **Developer mode** toggle switch in the top right corner of the Extensions page.

4. **Load Unpacked Extension**:
   - Click the **"Load unpacked"** button in the top left header.
   - Select the `/extension` folder from your local directory.

5. **Pin to Chrome Toolbar**:
   - Click the **Puzzle Icon (Extensions)** on your Chrome toolbar.
   - Click the **Pin** icon next to **Oblivion Focus**.

---

## 🛡️ Key Features

- **Popup Timer**: Quick access to 25m Focus, 5m Short Break, and 15m Long Break timers directly from Chrome's top bar.
- **Do Not Disturb (Notification Shield)**: When enabled and focus timer is running, the extension service worker automatically suppresses and clears browser notifications.
- **Screen Keep Awake**: Keeps your screen active without dimming during deep focus sessions.
- **Quick Task List**: Add and check off micro-goals during your focus blocks.
- **1-Click Open Web App**: Instantly launch the full Oblivion atmospheric studio app.
